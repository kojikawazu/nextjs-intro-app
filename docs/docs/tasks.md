### 詳細: #1 Skills アニメーション遅延バグ

- **現象**: 「and more...」ボタン押下時、新しく表示されるスキルカードのアニメーションが大幅に遅れる
- **原因**: `animationDelay` の計算に `visibleSkills` 配列全体の `index` を使用しており、追加カードの遅延時間が累積する
- **修正方針**: 新規追加カードのみにアニメーションを適用し、相対インデックスで遅延を計算する
